# Moonlit Violet Courtyard

Create a 2D game courtyard using Phaser 3, using the uploaded horizontal image as the visual design reference.



Rebuild the courtyard inside the game engine rather than displaying the image as a static background.



Preserve the visual style, colors, and perspective of the reference: glossy purple floor, stone walls, pillars, purple banners, warm lighting, plants, and a nighttime city background.



Build the environment using separate layers so characters can later move in front of and behind environmental elements.



Make the courtyard landscape-oriented and responsive to mobile screens. Define the walkable floor area and its boundaries.



Do not use a 3D environment. Do not add characters, furniture, or other objects at this stage.



Final goal: A fully constructed 2D courtyard inside Phaser 3, not a static image displayed on the screen.
